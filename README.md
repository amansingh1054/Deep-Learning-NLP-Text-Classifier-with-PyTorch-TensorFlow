# Deep Learning SMS Spam Classifier (PyTorch)

A complete, reproducible NLP classification demonstration with a multilayer neural network.

## Features
- TF-IDF text vectorization (unigrams and bigrams)
- PyTorch feed-forward neural network with **BatchNorm1d** and **Dropout**
- Stratified train/validation/test split; vectorizer fitted on training data only
- Early stopping using validation loss, checkpoint restoration
- Training/validation loss and accuracy curves
- Test metrics, confusion matrix, classification report
- Unseen SMS predictions with spam/ham confidence scores

## Dataset transparency
`data/sms_messages.jsonl` contains **720 synthetic, template-generated messages** (360 spam, 360 ham) created solely for a runnable educational demo. **It is not a real-world benchmark**, and reported test performance may be inflated by template overlap. For real deployment, replace this dataset with a representative labeled SMS dataset, use group/template-disjoint splits, and retrain/evaluate.

## Run locally
```bash
python3 -m venv .venv
source .venv/bin/activate  # macOS / Linux
pip install -r requirements.txt
jupyter notebook NLP_Spam_Classifier.ipynb
```
Run **Kernel → Restart & Run All**. Notebook works when opened from the project root. It also supports running from a `notebooks/` folder.

## Outputs
- `NLP_Spam_Classifier.ipynb`: executable notebook **with saved example training outputs**
- `figures/training_curves.png`: loss and accuracy chart
- `figures/confusion_matrix.png`: held-out test confusion matrix
- `models/spam_classifier.pt`: PyTorch model checkpoint (generated by training)
- `models/tfidf_vectorizer.pkl`: fitted TF-IDF vectorizer (generated by training)
- `models/label_mapping.json`: label mapping

## Important
This is a learning project, not a production spam filter. Do not treat synthetic-data test accuracy as evidence of generalization to real messages. Only load model/vectorizer files from trusted sources.

## Tech stack
Python, PyTorch, scikit-learn, pandas, matplotlib, seaborn, Jupyter.
